# 词力闯关 · 雅思单词像素版

一个轻松、像素风的雅思单词记忆小游戏。词库已内置《雅思词汇真经》整理文本：**1661 个单词、11 个章节**（自然地理 / 植物研究 / 动物保护 / 太空探索 / 学校教育 / 科技发明 / 文化历史 / 语言演化 / 娱乐运动 / 物品材料 / 时尚潮流）。

纯前端应用，无需联网、无需安装数据库，学习进度保存在浏览器本地。

## 玩法

- 每组 10 个单词，屏幕中间显示单词并自动朗读（可点按钮重读）。
- 从两个中文选项里选出正确释义。
- **界面不显示倒计时**：系统内部仍会记录你是否在 3 秒内答出——3 秒内答对 = 熟练（记忆等级 +1）；超过 3 秒答对 = 不熟练（复习间隔缩短）；答错 / 不认识 = 进错词本。
- **一组结束自动重做错词**：10 个词完成后，会把这一组里答错的单词单独再考一遍，最后才结算。
- 答对后展示完整释义（多义项）、例句和补充记忆点（词组、派生词等），并朗读例句。
- 按艾宾浩斯遗忘曲线安排下次复习：5 分钟 → 30 分钟 → 12 小时 → 1 天 → 2 天 → 4 天 → 7 天 → 15 天 → 30 天。

## 电脑上打开

直接双击 `index.html` 用浏览器打开即可（推荐 Chrome / Edge）。

## 手机上使用（iPhone）

苹果手机不能直接安装本机的网页文件，最实用的方式是把它做成 **PWA（添加到主屏幕）**，效果接近 App：全屏、有图标、支持离线。

### 方式 A：电脑 + 手机连同一个 WiFi（最快，不需要任何账号密码）

1. 电脑上双击「**启动手机版.bat**」（在 vocab-game 文件夹里），窗口会显示 `http://192.168.x.x:8000` 这样的地址。
2. 手机和电脑连同一个 WiFi，用手机 Safari 打开这个地址，就可以开始记单词。
3. 想做成主屏幕图标：Safari 点「分享」→「添加到主屏幕」。

> 注意：手机打不开时，多半是 Windows 防火墙拦截了。允许 Node.js 访问网络，或临时关闭防火墙再试。
> 这种方式要求电脑开机且在同一 WiFi 下；要真正做到随时随地，请用下面的方式 B。

### 方式 B：部署到网上（随时随地可用）

#### 第一步：把网页部署到网上（任选一种）

- 最简单：打开 [Netlify Drop](https://app.netlify.com/drop)，把整个 `vocab-game` 文件夹拖进去，几秒后得到一个 `https://xxxx.netlify.app` 的网址。
- 或者上传到 GitHub Pages / Vercel / Cloudflare Pages 等任意静态托管。

#### 第二步：安装到 iPhone

1. 用 iPhone 的 **Safari** 打开部署好的网址（用 Safari，不是 Chrome）。
2. 点底部「分享」按钮 → 选择「**添加到主屏幕**」。
3. 确认名称后点「添加」，主屏幕会出现「词力闯关」图标。
4. 之后从主屏幕打开就是全屏应用，首次打开后**断网也能用**（Service Worker 离线缓存）。

### 关于「安装包」

iOS 不允许安装未签名的安装包。要上架 App Store 需要苹果开发者账号（约 $99/年）、Mac 和 Xcode 签名，属于另一套流程。**PWA「添加到主屏幕」是不花钱、不用 Mac 就能在 iPhone 上随时使用的最佳方案**，且本应用已按 PWA 标准做好了清单、图标和离线缓存。

## 词库与数据

- 词库由 `vocabulary.txt` 自动生成（见 `tools/build-vocab.js`）。以后更新了词库文本，在 `tools` 目录运行 `node build-vocab.js` 即可重新生成。
- 词义以真经文本为准（大部分单词本身带多个义项）；文档中缺失释义的 30 余个基础词已补齐；重复出现的多义词已合并；明显笔误（如 `carbon dioxied`、`维度`）已修正。
- 学习进度保存在浏览器本地（localStorage）。iPhone 的「添加到主屏幕」应用与 Safari 共享同一份存储。请定期在「词表与数据」里**导出进度备份**，换设备或清缓存后可导入恢复。

## 导入词表

主页 → 「词表与数据」→ 粘贴词表 → 「导入并合并」。

支持 CSV 或 JSON：

```
单词, 音标, 中文释义, 英文例句, 例句翻译, 分组
abundant, /əˈbʌndənt/, adj. 丰富的, Rain makes the pond abundant with frogs., 雨水让池塘里满是青蛙。, 示例·A
```

也可以点「下载 CSV 模板」拿到模板文件。

## 小技巧

- 网址后面加 `#demo`（如 `index.html#demo`）会直接开始一组词，方便快速预览。
- 支持键盘 A/B 或 1/2 答题。
